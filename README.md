# Dishit presentation demo

"You choose the food. We bring the chef."

An interactive prototype of three connected interfaces (customer app, chef app,
admin dashboard) sharing one booking from payment to payout, in the Dishit brand
(follows your device's light or dark setting).

This is a demonstration. All people, addresses and prices are fictional,
payments are simulated and no real data is collected. Your changes are kept
only in your own browser; press "Reset demo" to start again.
